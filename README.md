# INSPIRE_to_AAS

Research project: automatic generation of Asset Administration Shell (AAS v3) Submodel Templates from INSPIRE data models.

Part of a broader effort on management-level digital twins for land parcels.

## Status

Early research. Nothing in this repository is assumed correct until it has been tested and the result documented.

- [first_reaserch.md](first_reaserch.md): initial desk-research notes (LLM-assisted). These are **hypotheses to verify**, not established facts.
